To make this auto-update from your Adulting Tracker:

  1. In your Adulting Tracker, make a new tab called Brag
  2. In A1 put: =QUERY('YOUR_MAIN_TAB'!A:N, "SELECT N, D, A WHERE B='Complete' ORDER BY N DESC", 1)
  3. File → Share → Publish to web → select the Brag tab → CSV format → Publish
  4. Copy the published link, click Configure above, paste it in

The link gets saved in your browser so you only do this once.
